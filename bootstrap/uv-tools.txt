# bootstrap/uv-tools.txt — base uv tools, installed by the 90-python bootstrap stage.
#
# One tool per line: the package name, optionally followed by `uv tool install` flags
# (e.g. `--with PKG`, `--python VERSION`, `--prerelease allow`). `#` starts a comment.
#
# 90-python reads this file, then every overlay's bootstrap/uv-tools.txt in layer order; a later layer's line for the
# same tool replaces the earlier one. A tool that is already installed is skipped, so a changed line takes effect only
# after `uv tool install --force <line>` (or `uv tool uninstall <tool>` and a re-run).
